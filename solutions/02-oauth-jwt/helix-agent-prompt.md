# Agent-mode prompt — OAuth 2.0 with gateway-issued JWTs

Paste this to the Helix Agent as one message, replacing the `<<...>>` values. Why
it is worded this way, what the agent adds on its own, and what to check before
you trust it are in the
[README](README.md#build-it-with-the-helix-agent).

## Prompt

```text
Step 1:
Create a REST API called "<<02-oauth-jwt>>" in the <<test>> environment, proxying
https://jsonplaceholder.typicode.com. Three routes — GET /posts, GET
/posts/{postId} and POST /posts — passed straight through to the upstream.

Step 2:
Add one more route: POST /oauth/token, so an app
can trade its client credentials for a token generated by the gateway.
Update the previous 3 routes to validate the token generated by this endpoint.

Step 3:
Create a developer "<<oauth-jwt-user>>", a corresponding product and an app to work with the above API.
Give me the app's client id and secret.
```
